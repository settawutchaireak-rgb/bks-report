# BKS — GitHub Pages + Google Sheets CSV (v43)

เว็บไซต์ชุดนี้อ่าน Google Sheets CSV ที่เผยแพร่แล้วโดยตรงจากเบราว์เซอร์ ไม่ใช้ API Key, Service Account, Google Cloud, Apps Script หรือ Cloudflare

## วิธีนำขึ้น GitHub Pages

1. แตก `BKS-GitHub-v43-CSV.zip` จะได้ไฟล์เว็บไซต์ทันที ไม่ต้องแตก ZIP ซ้อน
2. เข้า https://github.com/ สร้าง repository ใหม่ เช่น `bks-report` เลือก **Public** สำหรับ GitHub Free
3. เลือก **Add file → Upload files** หรือ **uploading an existing file** สำหรับ repository ว่าง
4. ลากไฟล์และโฟลเดอร์ทั้งหมดจาก ZIP ขึ้น GitHub รวม `assets`, `data` และ `.nojekyll` แล้ว **Commit changes**
5. ตรวจว่า `index.html` อยู่หน้าแรกของ repository ไม่ได้ซ้อนอยู่ในโฟลเดอร์ `BKS-GitHub-v43-CSV`
6. ไป **Settings → Pages → Build and deployment**
7. Source เลือก **Deploy from a branch**
8. Branch เลือก **main** และ **/(root)** แล้ว **Save**
9. รอ GitHub เผยแพร่สำเร็จ แล้วเปิด URL ที่แสดงในหน้า Pages โดยทั่วไปคือ `https://ชื่อบัญชี.github.io/bks-report/`
10. เปิดรายงานรายได้ แล้วตรวจวันที่ ชื่อและยอด 5 กล่อง กราฟ และสัดส่วนรายได้

ไม่ต้องตั้ง Secrets, Build command หรือ GitHub Actions เพิ่ม หากเคยใช้ชุด Cloudflare ให้ใช้ repository ใหม่สำหรับชุดนี้เพื่อไม่ให้ไฟล์เก่าปะปนกัน

## ลิงก์ข้อมูลตั้งให้แล้ว

อยู่ใน `config.js` ตรง `csvUrl`:

https://docs.google.com/spreadsheets/d/e/2PACX-1vS6mjZaOOSbfp5ONND_0hLkex4UbSaZUT7J5oR8l8hb0D8dPMyKiONH6RiEFjBPRy7ivDLlJ4Vv9zBw/pub?gid=0&single=true&output=csv

`dataMode` ตั้งเป็น `live` แล้ว ไม่ต้องแก้ก่อนใช้งาน หากเปลี่ยนแท็บ/ไฟล์ในอนาคต ให้เผยแพร่ลิงก์ CSV ใหม่ แล้วแก้เฉพาะ `csvUrl` และ Commit

ข้อมูลในแท็บที่เผยแพร่เป็นข้อมูลสาธารณะ เว็บไซต์นี้ไม่มีระบบล็อกอิน การเก็บ repository เป็นส่วนตัวไม่ได้ทำให้ CSV ที่เผยแพร่กลับเป็นข้อมูลส่วนตัว

## วิธีอัปเดตระหว่างนำเสนอ

1. แก้ข้อมูลใน Google Sheet แล้วรอให้บันทึก
2. กด **อัปเดตข้อมูล** บนเว็บไซต์ ปุ่มจะหยุดรับการกดซ้ำระหว่างโหลด
3. ไม่ต้องแก้ GitHub ไม่ต้อง Deploy และไม่ต้องรีเฟรชทั้งหน้า

Google อาจใช้เวลาสักพักในการเผยแพร่ค่าที่แก้ใหม่เป็น CSV แม้กดอัปเดตแล้วอาจยังได้ค่าเดิมช่วงหนึ่ง ให้รอแล้วกดอีกครั้ง และตรวจว่าเปิดตัวเลือกเผยแพร่ซ้ำอัตโนมัติเมื่อแก้ไขในหน้าการเผยแพร่ของ Sheet

วันเวลาที่แสดงใต้ปุ่มคือ **เวลาที่เว็บไซต์อ่านข้อมูลสำเร็จล่าสุด** ตามเวลาไทย ไม่ใช่เวลาแก้ Sheet และไม่ได้รับรองว่าข้อมูลที่ Google เผยแพร่ได้เปลี่ยนแล้ว หากโหลดผิดพลาดจะแจ้งข้อความและเก็บข้อมูลที่แสดงอยู่เดิมไว้

## ข้อมูลที่เชื่อม

| ส่วน | ช่วงข้อมูล |
| --- | --- |
| ช่วงวันที่ | A1 |
| ชื่อ 5 กล่อง | A3:A7 |
| ยอด 5 กล่อง | B3:B7 |
| กราฟรายได้และชื่อปี | A10:D22 |
| กราฟเที่ยววิ่งและชื่อปี | A25:D37 |
| สัดส่วนรายได้ | ชื่อ A41:A50 และยอด N41:N50 |

กราฟพล็อตเฉพาะเดือนที่มีตัวเลขครบทั้งสองปีและชื่อเดือนตรงกัน ช่องว่างไม่นับเป็นศูนย์ แต่ตัวเลข 0 ใช้ได้

สัดส่วนรายได้เรียงยอดมากไปน้อย 5 อันดับแรก แล้วรวมรายการที่เหลือเป็น **อื่นๆ** โดยไม่รวมแถว 51 ซ้ำ

ชื่อกล่องจะแสดงตรงตามข้อความในชีต รวมทั้งการสะกดและสัญลักษณ์ หากอยากเปลี่ยนคำ ให้แก้ใน A3:A7

เมนูอื่นและรายงานย่อย รวมหน้าเป้าหมายรายได้ ยังใช้ข้อมูลตัวอย่างเดิม ยังไม่ได้เชื่อมข้อมูลเพิ่มจากแท็บอื่น

## ไฟล์สำคัญ

- `index.html` — หน้าตาและการทำงานของเว็บไซต์
- `sheet-csv.js` — อ่าน CSV แปลงตัวเลข จับคู่เดือน และจัดอันดับรายได้
- `config.js` — ลิงก์ CSV และโหมดข้อมูล
- `assets-manifest.js`, `assets/` — รูปภาพเดิม 59 ไฟล์
- `data/` — ข้อมูลตัวอย่างสำหรับเมนูเดิม
- `.nojekyll` — ให้ GitHub Pages เผยแพร่ไฟล์แบบเว็บไซต์คงที่

ไม่ต้องอัปโหลดไฟล์ `.gs`, `_worker.js`, `_routes.json`, `_headers` หรือกุญแจ Google เพิ่ม ชุดนี้ไม่มีไฟล์เหล่านั้น

## หากมีปัญหา

- หน้าเว็บ 404: ตรวจ Settings → Pages, branch `main`, `/(root)` และตำแหน่ง `index.html`
- รูปไม่แสดง: ตรวจว่าอัปโหลด `assets/` ครบ และเปิด URL ที่ลงท้าย `/ชื่อrepository/`
- โหลด CSV ไม่สำเร็จ: ตรวจอินเทอร์เน็ตและการเผยแพร่แท็บที่ `gid=0` ต้องเป็น CSV ที่เปิดอ่านได้โดยไม่ล็อกอิน
- โครงสร้างไม่ตรง: ตรวจว่าลิงก์ยังเป็นแท็บรายงานเดิม และไม่ได้ย้ายแถว/คอลัมน์ตามตารางด้านบน
- ค่ายังไม่เปลี่ยน: รอ Google เผยแพร่ CSV ใหม่ ไม่ต้อง Commit เมื่อแก้แค่ยอดในชีต
- ไม่ควรเปิด `index.html` ด้วยการดับเบิลคลิกทดสอบ เพราะเบราว์เซอร์อาจจำกัดการอ่านไฟล์ ให้เปิดผ่าน GitHub Pages

## การตรวจสอบก่อนส่ง

ทดสอบกับ CSV จริงจากลิงก์ที่ให้มาแล้ว รวมการแสดงรายงานในเบราว์เซอร์ผ่านเส้นทางโฟลเดอร์ย่อย การโหลดรูป การกดจุดกราฟและปุ่มอัปเดต พร้อมตรวจตัวอ่าน CSV ที่มีจุลภาค ช่องว่าง บรรทัดใหม่ และเครื่องหมายคำพูด

รูปเดิมตรวจ SHA-256 ตรงกันทั้ง 59 ไฟล์ วิดีโอยังคงใช้ลิงก์ Cloudinary เดิม ไม่ได้รวมไฟล์ MP4

ยังไม่ได้อัปโหลดหรือเปิด GitHub Pages ในบัญชีของคุณ ต้องทำขั้นตอนด้านบนก่อน
